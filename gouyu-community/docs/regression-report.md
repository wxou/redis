## 运行环境事实

本机实际环境与最初推测不同：MySQL 运行在 Windows 本机，Redis 运行在 VMware CentOS `192.168.100.128`。虚拟机内也存在 MySQL 服务，但其 root 凭据与应用原配置不同，因此本次验证使用能够由原应用配置证实的本机 MySQL，避免修改未知的虚拟机 MySQL 实例。
